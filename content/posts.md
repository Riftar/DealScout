## 2. Two sizes

Image: `posters/two-sizes-1600x900.png`

```
One listing page I fetched today.

Its data fields say the building is 60 m². The advert text says 62 m².

An agent that trusts one of them without checking can rank the wrong house first. So DealScout checks the page before it ranks anything.

#neatHack
```

Alt text: DealScout poster. One listing, two sizes for the same house: 60 square metres in
the page's data fields, 62 square metres in the advert text. A real listing on 99.co.

## 3. Ninety in a hundred

Image: `posters/ninety-in-a-hundred-1600x900.png`

```
I sampled 100 rows from my tracker of about 4,990 house listings.

90 were missing the land size, the building size, or both.

You can't judge a price without the size. So DealScout reads the sizes from the listing page itself.

#neatHack
```

Alt text: DealScout poster. 90 of 100 listings were missing a size, shown as a grid of 100
