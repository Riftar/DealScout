# Buyer Jobs on AWS, Fetcher unchanged

The Dashboard is a buyer website on AWS: a Job stores a Brief, selected Portals from an allowlist, and a daily Asia/Jakarta schedule. Each firing is a Run; any Brief change is a new Job. Collect stays the existing Fetcher (robots.txt, no bot-evasion). Agent-Reach and Portal search pages were rejected. Worth on the list is Valuation ratio when Comps exist, not an eval score. The Dashboard URL is public. Snapshots stay off that site; only Shortlist and Listing fields are shown.
